================================================================================
WHAT DATA IS CAPTURED
================================================================================

For each action decision:
  - Turn number and step within turn
  - Player index (0 or 1)
  - Selection type (MAIN, ATTACK_TARGET, etc.)
  - Selection context
  - Count of legal options
  - Raw select options from observation
  - Parsed actions with indices and descriptions
  - Chosen action details
  - Integer returned to environment
  - Validation pass/fail status
  - Any validation errors
  - Any decision engine errors

This data enables root-cause analysis of any illegal actions.

================================================================================
VALIDATION LAYERS EXPLAINED
================================================================================

Layer 1: Null Check
  Catches: Decision engine returns None
  Fallback: First legal action

Layer 2: Bounds Check  
  Catches: action_index outside [0, N-1] range
  Fallback: First legal action

Layer 3: Identity Check
  Catches: Action object not in legal_actions tuple
  Uses: Object identity check, then equality fallback
  Fallback: First legal action

Result: NEVER returns illegal action to environment

================================================================================
TECHNICAL DETAILS
================================================================================

Three-Layer Validation Flow:
  act() receives observation
    → builds decision artifacts
    → calls _choose_action() 
      → DecisionEngine.decide() validates action in legal_actions
    → calls _validate_action_legality()
      → Layer 1: Null check
      → Layer 2: Bounds check
      → Layer 3: Identity check
      → Returns valid action or fallback
    → calls _trace_action_decision()
      → Records to global trace collector
    → Returns ActionSelection with returned_integer

At Game End:
  _finish_replay_if_terminal() is called
    → Prints trace summary to console
    → Exports trace JSON to outputs/replays/trace_*.json
