================================================================================
WHAT WAS IMPLEMENTED
================================================================================

Added a new CLI flag to the local runner: --stop-on-invalid

BEHAVIOR:
- Default: False (disabled)
- When enabled: Stops immediately if any game ends with INVALID status
- Prints clear diagnostic message with game number, statuses, rewards
- Preserves all replay/debug output
- Returns non-zero exit code to indicate error
- Does not continue running remaining games

CODE CHANGES:
- run_local.py: Added flag to argument parser
- run_local.py: Added INVALID detection logic in run_local_games()
- run_local.py: Added diagnostic message printing
- README.md: Added usage examples and documentation
- docs/phases.md: Added phase history entry

================================================================================
USAGE
================================================================================

Run 100 games and stop on first INVALID:
  python run_local.py --games 100 --stop-on-invalid

Run with replay logging:
  python run_local.py --games 50 --stop-on-invalid --replay

Run with custom HTML output:
  python run_local.py --games 10 --stop-on-invalid --html result.html
