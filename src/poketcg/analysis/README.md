# analysis

Reusable factual queries over parsed game state and typed legal actions.

This package owns:

- game-state analysis,
- board and hand inspection helpers,
- Pokemon and attack fact queries,
- typed legal-action filtering,
- lightweight cached aggregate views.

This package must remain free of:

- decision making,
- heuristics,
- scoring,
- search,
- learning,
- policy selection.
